#02

IoT Appliance Energy Usage Analysis from Large-Scale CSV Datasets

The primary goal of this project is to uncover standard usage patterns for household appliances by leveraging high-frequency power consumption data gathered from numerous smart plugs and IoT devices. The extensive dataset comprises several large-scale CSV files—one for each appliance—each containing around 1 million records, highlighting the massive volume of data involved. #03

Optimized Demand Response Program Using Reinforcement Learning and Bayesian Optimization

This project demonstrates a demand response program designed to allocate energy resources efficiently while encouraging participants to reduce consumption during peak hours. The program employs a combination of reinforcement learning (RL) and Bayesian optimization to maximize overall utility and fairness among participants in a reverse auction setting. By evaluating bids and utility values, the program identifies the most suitable participants to receive incentives. Initial reward values are calculated through a numerical method, and the RL process fine-tunes decisions over time, guided by optimized hyperparameters. The result is an efficient and dynamic energy allocation model that balances economic and operational goals.

Key Advantages

Intelligent Demand Response Reinforcement Learning Fair Incentive Allocation
Github

Technologies:

Python, Reinforcement Learning, Bayesian Optimization, Energy Systems Modeling

#06

Synthetic Outlier Generation and Filtering

This project focuses on generating and refining synthetic outliers for data analysis. It uses Gaussian Mixture Models (GMM) to create local and global outliers based on the statistical properties of an input dataset. These outliers are then filtered iteratively using a K-Nearest Neighbors (KNN) classifier, ensuring the refined datasets are accurate and reliable. The final local and global outlier datasets are saved for further use in anomaly detection or model validation tasks.

Key Advantages

Synthetic Outlier Generation GMM-Based Data Modeling KNN-Powered Outlier Refinement
Github

Technologies:

GMM, KNN, Anomaly Detection, Python
